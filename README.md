# Travel Agent Management System

A **C-based Travel Agent Management System** developed as a university project. The system is designed to manage customers, tour packages, bookings, payments, and other travel-related operations through a menu-driven console application.

## Project Overview

The Travel Agent Management System uses the **C programming language** and **text files** for storing and retrieving data. The project is organized into separate source files, header files, and data files for easier maintenance.

## Main Features

### Customer Management

* Customer registration and sign-up
* Customer information management
* Customer search and display
* Customer information stored in data files

### Tour Package Management

* Add and manage tour packages
* Tour categories
* Package status management
* Tour type selection
* Package cost management
* Display and search tour packages

### Booking Management

* Create tour bookings
* View booking information
* Search booking records
* Booking cancellation
* Booking status management

### Payment Management

* Payment information management
* Payment status tracking
* Booking amount management

### Seat Management

* Seat availability management
* Seat allocation for bookings

### Reports & Statistics

* Display system records
* Booking-related information
* Customer and package information

## How to Run

1. Download or clone this repository.
2. Open the file `TRAVEL AGENT MANAGEMENT SYSTEM.cbp` using **Code::Blocks**.
3. Make sure the `Source`, `Header`, and `Data` folders remain in their original locations.
4. Build and run the project from Code::Blocks.

## Data Storage

The system uses `.txt` files to store application data such as customer, booking, and tour package information.

The data included in this repository is **sample/demo data created for project testing and demonstration purposes**.
